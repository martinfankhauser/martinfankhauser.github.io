Code

Research code in R and Stata. The packages below live in the public repository martinfankhauser/code_base.

Intervalregression Beta

R · folder INTERVALREG/

Partial-identification estimator and confidence sets for a scalar regression when the regressor and/or the outcome are observed only as intervals (or are missing). Implements worst-case interval regression for linear and probit models, with an identified-set estimator and bootstrap confidence sets.

GitHub README

SVARs

R · folder SVARs/

Bayesian structural VARs in the Arias–Rubio-Ramírez–Waggoner framework. Three identification routines share the same building blocks (orthogonal rotations and volume-element importance sampling) but target different restrictions:

Proxy SVAR

Bayesian proxy-SVARs with external instruments (optional impact sign restrictions).

Arias, J. E., Rubio-Ramírez, J. F. and Waggoner, D. F. (2021), “Inference in Bayesian Proxy-SVARs,” Journal of Econometrics 225(1), 88–106.

GitHub README

Zero-sign SVAR

Sign and zero restrictions on impulse responses at any horizon (including the long run).

Arias, J. E., Rubio-Ramírez, J. F. and Waggoner, D. F. (2018), “Inference Based on Structural Vector Autoregressions Identified With Sign and Zero Restrictions: Theory and Applications,” Econometrica 86(2), 685–720.

GitHub README

Zero-sign + systematic component SVAR

Sign and zero restrictions on the structural coefficients A0 (policy rule) as well as on impulse responses.

Arias, J. E., Caldara, D. and Rubio-Ramírez, J. F. (2019), “The systematic component of monetary policy in SVARs: An agnostic identification procedure,” Journal of Monetary Economics 101, 1–13.

GitHub README

MCS

Stata · folder MCS/ · command modelconfset

Stata implementation of the Model Confidence Set: given losses (or forecasts) for competing models, the procedure returns the subset of models that cannot be rejected as best at a chosen confidence level.

Hansen, P. R., Lunde, A. and Nason, J. M. (2011), “The Model Confidence Set,” Econometrica 79(2), 453–497.
